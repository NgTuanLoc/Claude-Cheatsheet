System Design Cheatsheet

The components of a backend system, the workflows that connect them and the patterns that keep them up — from the numbers that size a design to the failures that break it. Examples use C#, SQL and Azure; the ideas carry to any stack. Start from the request traced below — each tagged hop opens the section that explains it — or pick a task.

Default to boringA modular monolith, one relational database, a cache and a queue carry most products a long way.
Every call can failTimeouts, retries with jitter, idempotency keys and dead-letter queues are the baseline, not extras.
Numbers pick the partsEstimate traffic, storage and latency budgets before choosing components; the estimator is in EST.
